## 🆘 Troubleshooting

### Problem: "The application failed to start"
- Make sure you extracted the file (not opened the zip directly to run).
- Right-click the `.exe` file and choose **"Run as administrator"**.

### Problem: My antivirus blocked the file
- This is a false positive. The file is safe.
- Add an exception in Windows Defender:
  - Go to `Windows Security` > `Virus & threat protection`.
  - Click `Exclusions` > `Add exclusion` > `File`.
  - Select the `.exe` file.

### Problem: The download is too slow
- Try pausing and resuming the download.
- Use a wired internet connection if possible.
- Try again later (servers might be busy).

### Problem: No players show up in the app
- Make sure the folder named `Configs` is next to the `.exe` file.
- If missing, redownload and extract the whole package again.
