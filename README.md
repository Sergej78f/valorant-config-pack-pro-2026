## FAQ

**How do I import a crosshair?**  
Copy the crosshair code from the tool and paste it in Valorant Settings → Crosshair → Import Profile Code.

**Does the sensitivity converter work from CS2?**  
Yes — enter your CS2 sensitivity and mouse DPI, it outputs the exact Valorant equivalent.
